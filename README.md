# LangNation Cloud Platform

AWS Capstone Project for a secure, highly available, containerized learning platform with AI/RAG capabilities.

## Core Technologies

- AWS
- Terraform
- Docker
- Amazon ECR
- Amazon ECS
- AWS Fargate
- Application Load Balancer
- Amazon RDS / Aurora
- Amazon S3
- AWS Lambda
- Amazon SQS
- Amazon SNS
- Amazon EventBridge
- AWS Step Functions
- Amazon Bedrock
- OpenSearch Serverless
- CloudWatch
- IAM
- KMS

## Environment

Primary development region:

`us-east-1`

The sandbox environment is recreated using Terraform because resources are automatically cleaned up daily.
